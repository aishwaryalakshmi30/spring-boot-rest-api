# Spring Boot REST API

A simple REST API project built using Java and Spring Boot to perform CRUD operations on user and bank account data.

## Technologies Used

- Java 17
- Spring Boot
- Spring Web
- Maven
- REST API
- HTML
- CSS
- JavaScript
- Postman
- VS Code / IntelliJ IDEA
- Git & GitHub
